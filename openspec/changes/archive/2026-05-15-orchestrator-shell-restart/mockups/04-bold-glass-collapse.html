Collapsed · 64 px

  • Width: 64 px. Vertical padding stays, horizontal padding shrinks to 8 px.
  • Brand collapses to mark only; collapse button moves below brand, centred.
  • Search becomes icon-only; click still opens ⌘K palette.
  • Items: justify-content: center, label + badge hidden.
  • Hover any icon → tooltip popover shows label + badge count (Radix Tooltip).
  • Active item keeps gradient pill, slightly larger radius (12 px) so it reads as a tile.
  • Section labels collapse to · · · separators (or hide entirely — decide later).
  • User card: avatar only, click still opens menu.

Behavior

  • Toggle: header button + ⌘\ keyboard shortcut (Linear convention).
  • Transition: width .25s ease. Labels fade with opacity via Framer Motion or pure CSS.
  • State persists in localStorage under orchestrator.sidebar.collapsed.
  • Tablet (< 1024 px): defaults collapsed.
  • Mobile (< 640 px): sidebar becomes a drawer triggered by topbar burger; expanded/collapsed setting ignored.
  • Tooltips only render when collapsed === true — wrap each item in <Tooltip> from @/components/ui/Tooltip.

Component anatomy

  • Sidebar — owns collapsed state + toggle.
  • SidebarBrand — mark + name + version, hides text on collapse.
  • SidebarSearch — opens ⌘K palette, icon-only on collapse.
  • SidebarSection — label + nav group, label hides on collapse.
  • SidebarItem — icon + label + optional badge; wraps in Tooltip when collapsed.
  • SidebarUser — avatar + name + role, hides text on collapse, opens DropdownMenu on click.
  • Driven by navItems registry (already exists) + feature registry merge.
