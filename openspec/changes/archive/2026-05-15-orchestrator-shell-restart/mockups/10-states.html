Pattern rules

  • Skeletons on first paint when route has no cached data. Match the shape of real content (rows, cards, header). Shimmer = 1.4s ease.
  • Empty states always show: glyph, headline, one-line guidance, primary action (when applicable). Calm tone — no exclamation marks.
  • Errors degrade gracefully: full-page only when the route cannot render at all. Inline alert when partial data still useful. Toast for mutation failures (5s auto-dismiss, retry action).
  • Refetch = blur overlay on stale data + centered spinner. Never replace with skeleton (jank).
  • Buttons show inline spinner replacing icon, label stays, button disabled.
  • FHIR: surface error OperationOutcome.issue[0].diagnostics in dev only. Users see friendly Dutch copy + HTTP status code.
