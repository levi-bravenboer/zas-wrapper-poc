C · Glass

Floating + translucent

  • Feels deliberate, "designed"
  • Page bg can carry subtle gradient or grain
  • Active item = white card with hairline shadow
  • Risk: backdrop-filter on older devices
D · Dark

Contrast sidebar

  • Strong visual anchor + premium tool feel
  • Teal accent pops harder on dark
  • Permanent ⌘K search slot in sidebar
  • Risk: contradicts "light theme only" rule — would need spec amend
E · Edge

Brand-led light

  • Stays inside light theme rule
  • Active item: 3px teal bar + teal-tinted gradient
  • Search inline, section labels separate groups
  • Most conservative of the three
