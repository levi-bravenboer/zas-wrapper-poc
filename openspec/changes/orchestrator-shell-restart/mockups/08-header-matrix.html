Reading the matrix

  • P · Simple looks deliberate on Dashboard, but loses navigation on Tasks (no filter tabs in header), and looks bare on the Patient detail (no breadcrumb, no sub-page tabs).
  • Q · Eyebrow + tabs reads as the same component everywhere. The eyebrow pill adapts: date on Dashboard, status on Patient, summary on Tasks. Tabs always present.
  • R · Breadcrumb + tabs shines on Patient (real depth), but the crumb is redundant on Dashboard / Tasks (single-segment) — it just shows the page name.
  • Hybrid possible: render crumb only when route depth > 1; render eyebrow only when supplied; tabs always available but optional.
