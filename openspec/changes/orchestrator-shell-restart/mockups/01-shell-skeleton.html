A · Sidebar only

  • Less chrome, more page real estate
  • Page header lives inside the content area — uniform with detail pages
  • Search/cmd-k can be triggered globally without a visible bar
  • Linear-flavor restraint reads as deliberate
  • Mobile collapse simpler (one panel to slide)

B · Sidebar + topbar

  • Persistent search field visible
  • Breadcrumb slot for deep pages (patient → task)
  • Slot for user menu / notifications / theme later
  • Familiar to HiX users (similar chrome)
  • Sticky context when scrolling long pages
Click a mockup in the browser to record your choice, or just tell me in the terminal. Both can also be combined (e.g. topbar appears only on detail pages).
