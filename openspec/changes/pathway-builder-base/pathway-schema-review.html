Inherited columns

Every table below inherits from a SQLAlchemy abstract base — these columns are present on every row but not repeated in each card.

Entity → AuditableEntity → TenantOwnedEntity

Entity (root for all rows): id, created_at, updated_at, deleted_at.

AuditableEntity (adds): created_by, updated_by, deleted_by — FK users.id ON DELETE RESTRICT.

TenantOwnedEntity (adds): tenant_id — FK tenants.id ON DELETE RESTRICT, NOT NULL, indexed.

Soft delete: deleted_at IS NOT NULL means logically removed. BaseRepository.list() filters them by default.
