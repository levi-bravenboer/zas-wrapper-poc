How time reads

  • Phase = chapter band (spans width = duration in days)
  • Day = X-position derived from cumulative timing
  • Pill = lifecycle of that block's time field
  • Dashed purple = data-flow edge (runtime field source)

Trade-offs

  • + Time + phase visible at a glance
  • + Day axis is the spatial anchor — drag block, day updates
  • − Day-derived-from-X couples logic to layout (drag = data change)
  • − Open-ended phases (Nazorg ∞) hard to size

How time reads

  • Phase = colored stripe on block edge + label in meta
  • Day = X-position aligned to ruler (visual hint, not authoritative)
  • Block carries its own phase explicitly — drag freely, phase stays

Trade-offs

  • + Layout decoupled from data (no surprise drags)
  • + Phases not sized — open-ended phases work fine
  • + Block always knows its phase even if axis hidden
  • − Phase boundaries less visible (no big band)
  • − Author must explicitly set phase on each block
