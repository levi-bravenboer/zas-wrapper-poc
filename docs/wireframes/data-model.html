Pathway data model

Eleven tables. Relational with one purposeful jsonb (pathway_block.config) and one opaque text payload (pathway_block_luscii_extension.payload). Every per-pathway table inherits TenantOwnedEntity from the repo base — id, tenant_id, created_at / updated_at / deleted_at, and audit FKs come for free.

Locked decisions on this shape

D1 — Pathway = aggregate root + 10 cascade-delete child tables. Not a JSONB graph blob.
D2 — Block-type catalogue is server-owned code; GET /pathway-blocks returns it.
D9 + D10 — Lanes: pathway_lane_kind catalogue + per-pathway pathway_lane instances. Block always FKs a real lane row.
D11 — Phases per pathway, ordered. PoC: decorative only (no duration, no anchor). Not navigable.
D12 — Time on block.duration + edge.delay via shared pathway_timing_value. PoC kinds: fixed + enrollment. runtime parked in MVP delta. CHECK-constrained, no JSONB.
D13 — Block cards fixed-width (~175px). Smart time tape deferred post-PoC.
D14 — Phase templates live in code (mirror D2). pathway_phase.template_id = soft pointer, no FK.
D15 — Per-pathway tables inherit TenantOwnedEntity: tenant_id, audit FKs, timestamps, soft delete free.
D16 — No design-time entry block. Enrollment (F4) picks the start.
D17 / D18 — Runtime timing + per-field runtime resolution deferred to MVP, together with output_schema on block-type catalogue.
D19 — Branches only on blocks whose catalogue entry advertises branching support. Enforced app-side (Pydantic), not DB.
D20 — pathway_edge UNIQUE on (source, target, branch) NULLS NOT DISTINCT. UI also blocks duplicate drags.
Naming exception — pathway_block.config is the ONLY jsonb. Validated at the app boundary against the catalogue's per-type config_schema.

How the tables connect

Validation rules at the app boundary

pathway_block.type must exist in the block-type catalogue.
pathway_block.config must conform to the catalogue's per-type config_schema (Pydantic on save, rjsf on input).
pathway_block.lane_id NOT NULL — every block sits on exactly one real lane row.
pathway_block.phase_id NOT NULL and must reference a phase of the same pathway.
pathway_timing_value CHECK enforces exactly one column-set populated per kind. Contradictions surface as 422. Unsupported kind (e.g. runtime) → 422.
pathway_edge.source_branch_id, when set, must belong to source_block_id.
pathway_branch only allowed on blocks whose catalogue entry supports branching (D19; PoC: decision).
UNIQUE on pathway_edge (source_block_id, target_block_id, source_branch_id) NULLS NOT DISTINCT (D20). UI also prevents duplicate drags.
pathway_block_field_resolution.field_path must exist in the block's config_schema.
UNIQUE (pathway_id, ord) on both pathway_phase and pathway_lane.
Cascade-delete from pathway through every aggregate child table on pathway delete.
Luscii payload round-trips byte-equivalent. Backend never interprets.
