Locked rules

  • Block card width never scales with duration. Only the tape segment scales.
  • Each block has a duration pill (⏱ 3d / ⏱ instant / 👤 0–7d).
  • Anchor line = dashed vertical from tape segment start down to block top-left.
  • Edge (block → block) carries its own delay, rendered as a tape segment between block-duration segments.
  • Slack segment (dashed grey) = phase budget remaining at default values.
  • Long waits (30d timer) push following blocks far right via tape, never widen the block.
