Variable gap between blocks · 3 layout sub-variants

A1 · A2 · A3
Scenario: 3 blocks chained inside one phase. B1 takes 3 days (fixed) · B2 triggers X days after B1 (X = enrollment-set, default 0) · B3 triggers 4 days after B2 (fixed).
Problem: B3's day is unknowable at design-time. How do we render it on a day-axis canvas?

A1 · Gap pills on edges, downstream marked "may shift"

Each edge carries a pill showing the gap (fixed days or 👤 enrollment). Downstream blocks positioned by default values, dashed border + "may shift" tag.

How it reads

  • Edge gap pills declare the timing relationship between adjacent blocks
  • Downstream blocks live at their default day position
  • Dashed border + "may shift" tag on any block whose actual day depends on an enrollment-set upstream gap
  • Day axis shows default layout — re-renders when caregiver enters values at enrollment

Trade-offs

  • + Clear: each gap shown where it belongs (on the edge)
  • + Downstream blocks visibly tagged as variable
  • + Day axis still useful (defaults)
  • − Author must give a default for every enrollment-gap (or canvas can't position B3)

How it reads

  • Author declares min/max for parameterizable gaps (e.g., 0..7d)
  • Downstream blocks render inside a tinted range bracket showing all possible days
  • Block positioned at midpoint or min — the bracket carries the truth
  • Phase duration check derives from cumulative max

Trade-offs

  • + Honest about uncertainty
  • + Phase fit visible (does max range still fit in phase duration?)
  • + Constrains caregiver at enrollment to the declared range
  • − Author must declare min/max (more authoring work)
  • − Brackets stack visually (phases full of variable blocks = busy canvas)

A3 · Relative chains · drop the global day axis inside chains

Day axis applies to phase boundaries only. Within a chain, blocks placed by visual flow + gap pills carry the relative timing. No "global day" claim made about variable blocks.

How it reads

  • Day axis only marks phase boundaries — not absolute block positions
  • Gap pills carry the truth between blocks
  • Position = visual flow only, not data
  • "What day is B3 on?" answered at enrollment by walking the chain

Trade-offs

  • + Honest — never lies about absolute days
  • + No "may shift" tags needed everywhere
  • + Less authoring (no defaults, no min/max required)
  • − Loses the "day +5 means this" visual quick-read
  • − Phase fit harder to eyeball
