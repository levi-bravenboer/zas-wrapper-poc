ZAS platform — hosting cost breakdown

What we need to host, why we need it, and what it costs across three cloud providers, two deployment shapes and three growth projections. Pure hosting — excludes personnel/on-call, vendor licences (Luscii, ChipSoft), audits and app-store fees.

1 · The services we need — and why

Derived from the platform architecture after the MVP stack decisions (custom pathway engine instead of Temporal, Keycloak instead of Ory, native object storage instead of MinIO). Six components plus cross-cutting basics — that's the whole bill.

PostgreSQL database — highly available

scales with: patients in pathways · 5-yr rolling retention (75 GB → 350 GB → 2 TB)

Single relational store for everything operational: pathway state and scheduling for the custom engine, tasks, caregiver actions, the FHIR-aligned audit trail, Keycloak's identity data.

Why this way: Runs as primary + synchronous standby in two zones (multi-AZ) with point-in-time recovery — that posture is what backs the committed 99.9% SLA and the NIS2 continuity duty. Biggest single line on the bill at every tier.

Backend API

scales with: peak requests (sizing 100 → 150 → 300 req/s)

The application itself: REST API for the caregiver orchestrator (SPA) and the patient app, plus server-sent events for live updates.

Why this way: SSE means long-lived connections — instances must be always-on (no scale-to-zero) and load balancers need raised idle timeouts. Two small replicas at MVP for zero-downtime deploys, scaling out with traffic.

Background worker — custom pathway engine

scales with: open enrollments (8k → 23k → 110k concurrent)

Separate process running the pathway engine's timers, polling and retries ('wound check due in 3 days', 'questionnaire after 2 weeks'). Custom-built for MVP — the PoC's Temporal cluster was decided out.

Why this way: Isolated from the API so a burst of due tasks can't starve user requests. Same container image, different entrypoint.

Keycloak — identity

scales with: identity count — effectively flat cost (one JVM container)

Login and account management for caregivers and patients, brokering the Belgian eHealth OIDC instance as upstream identity provider.

Why this way: Self-hosted on purpose: managed identity products (Ory Network, Cognito, Entra External ID) bill per monthly active user — at 55k–155k MAU that recurring fee would dwarf the container it replaces. Authorization becomes app-level RBAC in the backend (PoC's Ory Keto decided out).

Object storage — attachments

scales with: ~10 MB per pathway patient (250 GB → 1.2 TB → 8 TB)

Wound photos and documents, uploaded/downloaded via presigned URLs so files never stream through the backend.

Why this way: Native provider storage (S3 / Blob / GCS) in both deployment shapes — 11-nines durability, lifecycle rules and versioning for ~€0.02/GB. The PoC's MinIO stays dev-only.

Load balancer / reverse proxy

scales with: flat

TLS termination, host routing, serving the orchestrator SPA, and the raised idle timeouts SSE needs.

Why this way: Single-VM MVP can do this with nginx on the box; from two app nodes (2030+) and in the managed shape it's the provider's load balancer.

Cross-cutting: monitoring, backups, registry, DNS, egress

scales with: egress scales with usage (250 GB → 750 GB → 3 TB/mo)

Provider-native logging/metrics/alerting (SLA + NIS2 incident duty demand it), DB + storage backups, a container registry for images, one DNS zone, and internet egress for API responses and photo downloads.

Why this way: Small individually, always present — every cell of the matrix includes them so nothing is hiding.

Deliberately not on this bill

Video, messaging, questionnairesrun on Luscii's infrastructure (SDK reused as-is) — also why our credible SLA ceiling is Luscii's own 99.9%
Medical record storageHiX is the record of truth; the Belgian 30-year retention duty lives there. ZAS keeps ~5 years of operational data, so storage plateaus
Patient app hostingnative app via App Store / Play Store; no patient-facing web to host
Peopleon-call rota for 99.9%, ops time, NIS2 compliance work — salary money, likely exceeds this entire cloud bill
Vendor licences & auditsLuscii, ChipSoft/HiX, pen-tests, ISO 27001 / NEN 7510 certification
