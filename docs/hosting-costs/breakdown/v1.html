3 · What is being hosted

Stack (MVP posture)
PostgreSQL · FastAPI-class backend API · background worker (custom pathway engine) · Keycloak identity (eHealth OIDC upstream) · native object storage · reverse proxy / LB
Decided out
Temporal (custom engine instead — optional add-on line), Ory Kratos/Keto (→ Keycloak + app RBAC), MinIO (→ provider object storage), per-MAU managed IdPs (cost trap at 55–155k MAU)
Not on this bill
Video/messaging/questionnaires (run on Luscii infra) · medical record storage (HiX is record of truth, 30-yr duty lives there) · patient app distribution (native, app stores)
SLA posture
99.9% all tiers (capped by Luscii's own 99.9%); multi-AZ DB + standby, PITR, quarterly DR drills; satisfies NIS2 proportionate-continuity duty
Retention
ZAS holds operational data ~5 yr rolling; storage plateaus (no 30-yr archive tier)
Regions
GCP europe-west1 (Belgium — preferred soil) · Azure France Central · AWS eu-west-3 Paris
